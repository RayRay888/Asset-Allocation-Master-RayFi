## 功能概览 / Features

- 四级资产树：一级 → 二级 → 三级（目标%）→ 四级（可选）
- 实际% / 目标% / 差距与调仓金额
- 多维分析：托管、底层资产、风险、风格、币种、流动性
- 行情刷新（含国内商品/股指期货按合约乘数计价）
- 中英界面切换（标题旁 中文 | EN）
- 使用说明页；导出 JSON 文件名为 `AA_` 加本地时间到分钟（样本名 `AA_random_V1`）
