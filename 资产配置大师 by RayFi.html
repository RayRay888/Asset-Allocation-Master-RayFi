这是什么

「资产配置大师 by RayFi」是一份单文件本地工具：用浏览器直接打开 HTML 即可使用，无需安装、无需服务器、也没有账号体系。你的持仓、目标%、托管列表、快照与界面偏好，只保存在本机浏览器的 localStorage（键名 assetAlloc_share_v2；界面偏好另用 assetAlloc_share_ui_v2）。从网上下载的 HTML 本身不含任何人的真实持仓；首次打开会看到虚构样本组合 AA_random_V1（约一亿量级的演示数据），方便你摸清流程后再改成自己的。

设计目标很朴素：把「目标配置」和「实际持仓」放在同一张可编辑的树上，随时看到缺口与再平衡方向；再用多维分析（托管 vs 底层资产、风险、风格、币种、流动性等）对照「钱在哪」和「风险在哪」。它面向认真做全球/多资产配置的个人投资者与家庭办公室式记账，而不是交易终端或投顾推荐引擎。

功能一览

配置树（一级→二级→三级→可选四级）：用层级组织资产大类、策略与具体持仓。目标% 通常写在三级（若某二级下所有三级目标都空，也可直接写在二级）；有金额时实际% 由金额自动折算，并显示目标与实际的缺口，方便再平衡。

持仓字段：名称、代码（symbol）、数量、单价、金额、计价币种等。金额可由「数量×单价」锁定，也可只填金额。点「刷新价格」可拉取美股/港股/日股/A股与加密等行情（失败时可手填）。行情来源：美股/港股/日股/A股用腾讯行情（备用 CNBC）；加密用 CoinGecko（备用 OKX/Hyperliquid/Kraken/Gate）。国内商品/股指期货：单价 = 行情 × 合约乘数（每手名义价值），数量填手数（空头为负）。

托管位置列表：维护券商/银行/钱包等托管名称，并在持仓行选择；分析页可按托管国家/地区汇总「钱在哪」。

分类标签：风险等级、投资风格、底层资产、流动性。未手动设置时按名称/代码/分类自动推断（灰色斜体），可在行右侧「🏷」修改；分析页按这些维度出双饼图与明细表。

分析页六维：托管分类、底层资产、风险、风格、币种、流动性；另有组合概览、三级旭日图、风险与税务提示。打印时主要输出分析页。

汇率与计价：可选 USD/CNY/HKD/EUR/JPY 等为计价币种；打开页面即可自动获取汇率（来源 open.er-api），失败时用缓存或内置默认值。

快照：在当前浏览器内保存时间点配置，便于对比；不能替代文件备份。换机/清缓存会丢。

导入/导出 JSON：文件名形如 AA_YYYY-MM-DD HH:mm.json（本地时间到分钟），含全部树、金额、目标%、托管、设置与快照。换电脑、换浏览器或替换新版 HTML 前务必先导出。

个人信息/税务提示与 AI 提示词：可填税务居民等，用于生成风险与税务提示，以及导出给大模型的组合说明（可脱敏）。界面支持中英切换；另有「恢复默认」回到样本 AA_random_V1（两步确认，执行前自动下载备份）。

怎么用（建议流程）

1. 首次打开：双击或用浏览器打开本 HTML。先浏览样本树，确认计价币种与汇率状态；需要时可点「恢复默认」重新载入 AA_random_V1。

2. 改成自己的树：在输入页增删一/二/三级，必要时加四级持仓；填写托管、代码、数量/单价或金额；用拖拽调整层级与顺序。

3. 设定目标%：在三级（或条件允许时在二级）写入目标权重，让合计接近 100%；对照实际% 与缺口列决定加减仓方向。

4. 刷新行情与标签：点「刷新价格」更新可报价标的；检查并修正风险/风格/底层资产/流动性标签。

5. 看分析页：切换到分析页，对照托管 vs 底层资产（例如中国 QDII 买标普：托管算「中」，底层算「美国」），再看风险与流动性结构。

6. 备份：定期「导出 JSON」存网盘；重要节点可再「存快照」。换新版 HTML 前务必先导出，再打开新文件并导入。

提示与注意

换版必备份：新下载的 HTML 不会自动带上你的持仓；数据在浏览器里。替换文件或清站点数据前先导出 JSON。

托管 ≠ 底层资产：托管回答「钱放在哪家/哪国」，底层资产回答「经济风险敞口在哪」。QDII、互认基金、ADR 等尤其容易混——请用分析页左右对照。

快照 ≠ 备份：快照只在当前浏览器；长期保存与迁移请用导出文件。

行情可能失败：网络、代码写法或数据源限流都会导致报价失败，可手填单价。数据源见「功能一览」中的行情与汇率说明。期货请确认乘数与手数符号（空头为负）。

非投资建议：税务与风险提示仅供参考；配置决策请结合自身情况与专业意见。

什么是资产配置

世界本来就不确定。资产配置就是先定你能扛多少风险、各类资产各占多少，再把钱按这个比例摆开——股票、债券、房子、黄金、不同国家、不同币种，都行。不是天天刷行情、凭感觉追涨杀跌。

还得分清两件事：钱在哪（银行、券商、钱包），风险在哪（真正敞口在哪块经济）。同是 QDII 买标普，钱可能在国内，风险却在美国。搞混了，再平衡容易做反。

做法其实很短：目标%写清楚，隔一阵对照实际%，偏了就调回来。少靠心情加仓。组合能挨过不同行情，比押中下一个风口管用。

最后拍板的是你。RayFi 这边就一个调调：长期、多资产、少口号，把账算明白比讲故事重要。
